Ví Điện Tử & Thanh Toán FoodPay

Kiểm tra số dư và thực hiện thanh toán an toàn (bảo vệ chống trừ tiền 2 lần).

Bắt đầu từ đâu?

  1. Xem trang Đặt món.
  2. Xem trang Thanh toán.
  3. Đọc js/api.js để biết cách gọi API bằng axios.
  4. Tạo trang mới: thêm file HTML trong pages/, script trong js/pages/, rồi thêm link vào js/layout.js.
